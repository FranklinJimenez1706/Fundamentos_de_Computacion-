# Glosario: Fundamentos de programación

**Algoritmo:** Conjunto finito de pasos para resolver un problema.

**Programa:** Instrucciones para que una computadora realice una tarea específica.

**Código fuente:** Texto escrito por una persona en un lenguaje de programación.

**Lenguaje de programación:** Conjunto de reglas y símbolos que permite escribir instrucciones para que una computadora las ejecute.

**Sintaxis:** Reglas para escribir correctamente las instrucciones.

**Variable:** Espacio de memoria al que se le asigna un nombre y que almacena un valor que puede ir cambiando.

**Constante:** Es como una variable, pero su valor no puede cambiar una vez establecido.

**Tipo de dato:** Clasificación del tipo de datos que almacena una variable.

**Operador:** Símbolo que indica una operación.

**Expresión:** Combinación de variables, valores y operadores que, después de evaluarse, da un resultado.

**Condicional:** Permite ejecutar instrucciones dependiendo de si se cumple o no una condición.

**Bucle:** Repite una instrucción mientras se cumpla una condición.

**Función:** Realiza una tarea específica, recibe datos y da un resultado.

**Parámetro:** Variable que recibe el valor que se le pasa a una función.

**Argumento:** Valor que se envía a una función al momento de llamarla.

**Retorno:** Valor que una función entrega como resultado al finalizar su ejecución.

**Arreglo:** Almacena una colección ordenada de elementos, accesibles mediante un índice.

**Objeto:** Entidad que agrupa datos relacionados entre sí.

**Método:** Función que pertenece a un objeto y que define un comportamiento o acción que ese objeto puede realizar.

**Evento:** Suceso que ocurre durante la ejecución de un programa.

**Compilador:** Programa que traduce por completo el código fuente escrito en un lenguaje de alto nivel a código máquina antes de ejecutarse, generando un archivo ejecutable independiente.

**Intérprete:** Programa que lee y ejecuta el código fuente línea por línea, en el momento, sin generar antes un archivo ejecutable independiente.

**Depurador (Debugger):** Herramienta que permite ejecutar un programa paso a paso, revisar el valor de las variables y detener la ejecución en puntos concretos para encontrar errores.

**IDE:** Entorno de desarrollo integrado; aplicación que reúne editor, compilador o intérprete, depurador y otras herramientas en un solo lugar.

**Editor de código:** Programa enfocado en escribir y modificar código, con funciones como resaltado de sintaxis, pero sin integrar por sí mismo un compilador o depurador completos.

**Biblioteca (Library):** Conjunto de funciones ya programadas que un desarrollador puede reutilizar en su propio código sin escribir esa lógica desde cero.

**Framework:** Estructura de trabajo que define reglas y componentes para organizar un proyecto; a diferencia de una librería, es el framework quien controla el flujo y llama al código del desarrollador.

**API:** Conjunto de reglas y funciones que permite que dos programas se comuniquen entre sí sin conocer los detalles internos del otro.

**Repositorio:** Espacio, local o remoto, donde se almacena el código de un proyecto junto con el historial de sus cambios.

**Control de versiones:** Sistema que registra los cambios hechos a los archivos de un proyecto a lo largo del tiempo y permite volver a versiones anteriores.

**Git:** Sistema de control de versiones distribuido que permite llevar el historial de cambios de un proyecto de forma local.

**GitHub:** Plataforma en línea que aloja repositorios de Git y añade herramientas de colaboración entre desarrolladores.

**Rama (Branch):** Línea de desarrollo independiente dentro de un repositorio, para trabajar en algo nuevo sin afectar el código principal.

**Commit:** Registro de un conjunto de cambios guardado en el historial del repositorio, con un mensaje que describe qué se modificó.

**Merge:** Proceso de combinar los cambios de una rama con otra, unificando el trabajo de ambas.

**Callback:** Función que se pasa como argumento a otra función para ejecutarse más adelante, normalmente cuando termina una tarea o evento.

**Programación síncrona:** Modelo en el que las instrucciones se ejecutan una tras otra, y cada tarea debe terminar antes de iniciar la siguiente.

**Programación asíncrona:** Modelo en el que ciertas tareas se ejecutan sin bloquear el flujo principal, permitiendo continuar con otras mientras esa tarea se completa.

**JavaScript:** Lenguaje de programación interpretado usado para dar interactividad a las páginas web, aunque también corre fuera del navegador (por ejemplo, con Node.js).

**TypeScript:** Lenguaje que extiende a JavaScript agregando tipado estático; su código se transpila a JavaScript para ejecutarse.
